cactusdb
Read-only database browser

Every database, one read-only window

cactusdb opens SQL Server, PostgreSQL, MySQL and MariaDB, Oracle, Firebird, SQLite, MongoDB, Redis, Neo4j and more from one browser page. Browse tables, views and procedures, run queries, and export to Excel, CSV, JSON or XML, without ever changing a row of your data.

  • 20+ database engines
  • Read-only by design
  • Excel, CSV, JSON & XML exports
  • Saved queries with versions
  • Compare & migrate databases
  • Backups & DDL scripts

Free and open source: github.com/albievan/cactusDB
