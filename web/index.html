New connection

Every saved connection has its own password. You need it to connect, edit or delete the connection, and to download its exported files. It also encrypts the saved username, password and queries.

Settings

When nobody clicks, types or scrolls for this long, cactusdb disconnects from the database. It never disconnects while something is running (a query, an export, a backup), and counts again from when it finishes. 0 means never. The default is 15 minutes. The setting is saved on the cactusdb server and applies to everyone using it.

Google Analytics

Off until a Measurement ID is set, and then still only for the people who say yes in their browser. Only which functions are used is sent (tabs, menu items, connect, export…), never data, SQL, names or addresses.

Command-line runs are sent by the server itself, so it needs to reach Google and an API secret (Admin → Data streams → your stream → Measurement Protocol API secrets). They wait at most 2 seconds for Google. They are always recorded in the usage log.

Checking…

Or update by hand: run one command on the computer cactusdb runs on, in the folder it's in, then restart cactusdb. Your saved connections and exports stay where they are. The setup scripts pick the right file for the system themselves; the other commands download one particular file as cactusdb (cactusdb.exe on Windows).
